# KAKU — 書く。

일본어 손글씨를 문자로 인식하고 **구절 단위로 변환 후보를 고르는** 실험용 웹사이트입니다.

## 사이트

- [KAKU 웹사이트](https://ggy5555.github.io/kaku/) (GitHub Pages를 활성화하면 접속 가능)
- [index.html](./index.html): HTML, CSS, JavaScript를 한 파일에 포함한 정적 웹앱

## 최초 배포

1. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
2. 저장소에 포함된 [Deploy KAKU 워크플로](./.github/workflows/deploy.yml)가 main 브랜치를 자동 배포합니다.
3. 자동 실행이 실패했다면 **Actions → Deploy KAKU → Run workflow**로 다시 실행합니다.

별도 빌드·서버·API 키 없이 페이지가 열리지만, **필기 인식 모델은 초기 실행 시 외부 네트워크에서 다운로드**합니다.

## 기능

- S펜/터치/마우스를 이용한 한 글자씩 쓰는 14칸 필기 영역
- 펜·지우개·획 되돌리기·다시 실행·전체 지우기
- 브라우저 ONNX Runtime Web의 일본어 단일 글자 인식 모델 연결
- 문장을 **구절별**로 선택하고 후보 확정, 합치기·나누기·직접 수정
- 유사 문자 후보: カ / 力, ロ / 口 등
- 복사, TXT 내보내기, 브라우저 자동 저장 및 저장 기록
- 모델 없이도 작동하는 **직접 입력**과 **예시 체험**

## 사용법

1. 왼쪽 첫 칸부터 **한 칸에 한 글자**씩 씁니다.
2. **필기 인식하기**로 각 칸을 인식합니다. 환경에 따라 모델이 작동하지 않을 수 있습니다.
3. 구절을 선택하고 문자 후보를 누릅니다. 구절을 합치거나 나눌 수도 있습니다.
4. **텍스트에 추가** 후 복사하거나 TXT 파일로 내보냅니다.

## 알려진 한계

- 완전 자유 필기 문장의 글자 경계를 자동 검출하지 않습니다. **한 칸에 한 글자**씩 써야 합니다.
- 구절과 후보 추천은 초기 사전 및 규칙 기반입니다. 상용 일본어 IME 수준의 문맥 분석은 제공하지 않습니다.
- 작은 가나, 구두점, 숫자 및 일부 한자 인식 정확도가 낮을 수 있습니다.
- 실제 Android 태블릿 S펜 인식, ONNX 모델 다운로드/CORS/WebAssembly 동작은 추가 실기기 검증이 필요합니다.
- 저장 내용은 브라우저 LocalStorage에 남으며 기기 사이에 동기화되지 않습니다.

## 모델 및 개인정보

- [LT8/japanese-handwriting-onnx](https://huggingface.co/LT8/japanese-handwriting-onnx) + ONNX Runtime Web
- 저장소에는 모델 가중치가 없으며 인식은 모델 다운로드 후 브라우저에서 실행됩니다. 모델 이용 조건과 라이선스는 원출처를 확인해야 합니다.
- 필기 획을 앱 운영 서버로 보내는 기능은 없습니다. 외부 폰트 및 모델 다운로드 요청은 발생할 수 있습니다.
