ENGINE NOTES

인식 엔진

ONNX Runtime Web과 공개 일본어 손글씨 단일 문자 모델을 사용합니다. 인식 연산은 기기에서 처리하지만, 첫 실행 때 모델 파일을 내려받으므로 인터넷 연결이 필요합니다.
현재 제한
한 칸에 한 글자씩 입력해야 하며, 작은 가나·구두점·숫자·일부 한자와 긴 문장 자동 구문 분석은 미지원 또는 정확도가 제한됩니다. 후보 사전은 초기 데모 규모입니다.
